# Changelog

All notable changes to this project will be documented here.

## [0.1.0] - 2026-08-11

### Added

- UTF-8 OCR import from one TXT file or a directory of per-page TXT files.
- Form-feed page splitting and filename-derived source-page mapping.
- Unicode, whitespace, line-wrap, hyphenation, and basic margin cleanup.
- Page-mapped JSONL and Markdown export.
- Literal and regular-expression full-text search CLI.
- Fictional bilingual sample data, documentation, and automated tests.
